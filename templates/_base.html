One file owns the frame now, so a change lands everywhere or nowhere. A page configures itself with top-level {% set %} straight after {% extends %} -- not with blocks, because the title and description are each needed in three places (title, og:, twitter:) and a block cannot be rendered more than once without being redeclared. page_title the part before "· reportscope". Omit on the home page, which gets the descriptive form instead. meta_description ~155 characters, written per page. Google composes its own snippet from body text when this is missing. layout "page" (default) gets the masthead, a <main> and the standard footer.
