# Reaction terms excluded from signal detection.
#
# Every line here is an analysis decision, not a technical detail: excluding a
# term changes what the tool reports. These are excluded because they describe
# something that happened to the PRESCRIPTION rather than to the PATIENT'S
# BIOLOGY. A disproportionality score on them measures how a product is
# packaged, dosed and dispensed -- real signals, but not pharmacological ones,
# and not what this tool claims to detect.
#
# Lines starting with # are ignored.

# -- Absence of an event, or a non-event -------------------------------------
NO ADVERSE EVENT
UNEVALUABLE EVENT
CONDITION AGGRAVATED

# -- Efficacy rather than harm -----------------------------------------------
# "The drug did not work well enough" is not an adverse reaction. WEIGHT LOSS
# POOR ranked fourth for semaglutide (ROR 39.2) purely because weight loss is
# what the drug is taken for -- the term cannot appear for a drug nobody takes
# to lose weight, so its disproportionality measures the indication.
DRUG INEFFECTIVE
THERAPY NON-RESPONDER
THERAPEUTIC RESPONSE CHANGED
THERAPEUTIC RESPONSE DECREASED
THERAPEUTIC RESPONSE UNEXPECTED
WEIGHT LOSS POOR
PRODUCT COMMUNICATION ISSUE

# -- Off-label / misuse ------------------------------------------------------
OFF LABEL USE
INTENTIONAL PRODUCT MISUSE
TREATMENT NONCOMPLIANCE

# dose-escalation schedule, not about the molecule. Left in, it would crowd
# out the pharmacological signals the tool exists to surface.
